# Runbook Writing Principles

- **Exact commands**, not prose ("gcloud run services describe alizia-api", not "check the service")
- **Numeric criteria** ("If X>Y -> Z", not "if it looks odd")
- **Scannable at 3am** — headers, code blocks, tables, not paragraphs
- **No tribal knowledge** — not "ask Juan", but "Juan P. on PagerDuty"
- **Direct links** to dashboards, not "the main dashboard"
- **The on-call team's language** — write it in the language the user uses or asks for; on-call is regional
- **School hours matter** — 10am with classes running != 3am

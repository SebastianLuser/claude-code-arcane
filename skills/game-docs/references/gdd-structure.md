# GDD Structure — Full Section Reference

| # | Section | Key content |
|---|---------|----------------|
| 1 | Summary | Table: genre, platform, engine, perspective, average session, target audience |
| 2 | Concept | Elevator pitch in 2-3 sentences. "It's like [A] but with [B]" |
| 3 | Design pillars | 3 pillars. Test: if a feature doesn't support ≥1 pillar → it's out |
| 4 | Art direction | Visual style, palette, references (or delegate to `/art-bible`) |
| 5 | Game feel | Visual/tactile feedback principles |
| 6 | Glossary | Table: term, meaning, forbidden alternatives |
| 7 | Core loop | Diagram + layer table (micro/mid/macro) with duration |
| 8 | Core system | Main flow, player mechanics, value tables |
| 9 | Levels/world | Generation (procedural/handcrafted/hybrid), types, difficulty progression |
| 10 | Enemies | Table: name, HP, damage, behavior, appearance. AI/patterns |
| 11 | Items/gear | Categories with effect, item balance |
| 12 | Economy | Resources (earning/spending), progression curve, meta-progression |
| 13 | UI/UX | Main screens, in-game HUD |
| 14 | Audio | Music per situation, key SFX |
| 15 | Scope | MVP checklist, roadmap per phase (Prototype→VS→Alpha→Beta→Release) |
| 16 | Open decisions | Table: question, options, status ([TBD] or decided) |

Optional appendices: balance formulas, stat tables, state diagrams.

Adapt the sections to the genre — a puzzle game doesn't need "enemies".

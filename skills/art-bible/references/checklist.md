# Checklist

### Core
- [ ] Visual Identity Statement (1-line rule + principles)
- [ ] Mood targets per game state (emotion, lighting, contrast)
- [ ] Shape language (silhouettes, geometry, UI shapes)
- [ ] Color system (palette + semantics + colorblind backup)

### Production
- [ ] Character design direction
- [ ] Environment design language
- [ ] UI/HUD visual direction
- [ ] Asset standards with concrete numbers

### Reference
- [ ] 3-5 references with what to take and what to avoid
- [ ] Explicit style prohibitions

# Anti-patterns

- Specs not anchored to the art bible — guaranteed visual inconsistency
- Duplicating assets that already have a spec in another context
- Generic generation prompts ("a sword") without style keywords or color anchors
- Vague visual descriptions ("looks cool") instead of specific ones ("angular silhouette, Threat Blue glow, 3-frame pulse animation")
- Made-up dimensions that don't match the Art Bible §8 tiers

# Checklist

```markdown
- [ ] Art bible read, §8 Asset Standards identified
- [ ] Source doc read, explicit and implicit assets extracted
- [ ] Asset list confirmed by the user
- [ ] Shared assets detected (no duplicates)
- [ ] Every spec has: dimensions, format, naming, visual description, art bible anchors
- [ ] Generation prompts with style keywords and negative prompts
- [ ] Sequential asset IDs, manifest updated
```

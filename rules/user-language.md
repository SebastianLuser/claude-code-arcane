# User Language

Skills, agents, rules and script output in this project are written in English. That never sets the language of the conversation.

- **Reply in the language the user writes in.** If they switch languages, switch with them. A skill written in English, an English error message or an English agent report is relayed in the user's language.
- **Files you write for the user follow the user**: notes, CVs, cover letters, messages and documents go in the language the user uses or asks for. A CV for a job posted in another language goes in the language the user chooses for it.
- **Code, commits, identifiers and data contracts stay as the project defines them.** Folder names, frontmatter keys, JSON fields and status values are a schema: keep them exactly as written, whatever language the conversation is in.
- **Subagents report in English; you translate.** When you delegate, ask for the result in English and give the user the outcome in their language.
